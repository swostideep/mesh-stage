Engine Features Architecture
C++ / WebGL Project

Surface
Mesher

A custom-built meshing pipeline designed for computational geometry. Generates isotropic, watertight surface meshes from raw CAD data with FEA validation Heat-map.

🌡️

FEA Quality Heatmap

Calculates 3D triangle skewness in C++ and projects the data as an interactive RGB heatmap directly onto the WebGL model.

👁️

Surface Manager

Parses complex STEP/IGES assemblies, extracting distinct topological faces to allow individual surface visibility toggling.

📐

Curvature-Adaptive Sizing

Utilizes OpenCASCADE to evaluate local surface curvature, dynamically refining mesh density around sharp features.

⚡

Multi-Threaded Engine

Executes parallel face-batching across available CPU cores via `std::async` for rapid geometric processing.
