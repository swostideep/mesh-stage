Pipeline
01 / IMPORT

Read and heal

STEP or IGES is imported through OpenCASCADE, then unified, tolerance-repaired and sewn so downstream stages see one consistent shell.

02 / DISCRETISE

Size the edges once

Every model edge is sampled a single time against a chordal sag tolerance. Two faces sharing an edge therefore receive identical nodes.

03 / TRIANGULATE

Mesh faces in parallel

Faces are handed out largest-first to an OpenMP pool. Each is triangulated in a metric-normalised parameter space and refined against curvature.

04 / AUDIT

Weld and verify

Face meshes weld through a spatial hash, then the result is checked for free edges, non-manifold edges, inversions and skewness before it is written.

Engine

Exact geometric predicates

Orientation and in-circle tests run in 128-bit integer arithmetic on a quantised lattice. The sign is always correct, so the triangulation cannot be corrupted by rounding.

Curvature-adaptive sizing

Element size follows a chordal sag tolerance through the local principal curvatures, so fillets and bores refine automatically while flat walls stay coarse.

Parallel by face

Faces are independent, so they are scheduled dynamically across cores with the largest first. Thread count is capped to the container's real CPU allowance.

Verified, not assumed

Watertightness, manifoldness, element orientation and the Delaunay property are all asserted by an automated suite rather than left to inspection.
